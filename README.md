- Product listing and browsing
- Shopping cart functionality
- Responsive design for mobile and desktop
- React Router for navigation
- Reusable React components
- Modern and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- React Router
- Git & GitHub
